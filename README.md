# Pennywise Mobile

Pennywise is a personal budgeting mobile application built with React Native and Expo, targeting iOS and Android.

## Tech Stack

- **Framework:** [Expo](https://expo.dev/) (SDK 57) + React Native 0.86
- **Routing:** [Expo Router](https://docs.expo.dev/router/introduction/) (file-based typed routes)
- **Language:** TypeScript (strict mode enabled)
- **Tooling:** ESLint (`eslint-config-expo`) + Prettier + custom repo rules

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Copy environment template:
   ```bash
   cp .env.example .env
   ```

3. Start development server:
   ```bash
   npm start
   ```

4. Run code quality checks:
   ```bash
   npm run check
   ```
